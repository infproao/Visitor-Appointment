# 图片/图标资源

访客预约原型用到的图片、图标资源。

| 文件 | 用途 | 说明 |
|---|---|---|
| `success-check.svg` | 成功对勾图标 | 提交成功页的绿色对勾（#23C343，海信成功色） |
| `qr-placeholder.png` | 二维码占位图 | 通行证/提交成功页的二维码占位 |
| `empty-state.png` | 空状态插画 | 无预约记录等空状态页 |

## 使用约定

- 成功对勾：提交成功页、状态反馈
- 二维码占位：通行证页、提交成功页、补授权弹窗（实际二维码 ≥ 200px，静区 ≥ 16px）
- 空状态插画：预约记录空状态、失效通行证

## 待补充（可选）

- 访客须知横幅插画
- 相机、搜索、编辑、删除等图标

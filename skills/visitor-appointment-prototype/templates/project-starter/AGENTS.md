# 访客预约原型 · 工程内设计规范（供 AI 编码助手执行）

> 本工程是「访客预约」H5 原型的可运行 starter。AI 编码助手在本工程内**新增或修改页面**时，
> 必须遵守以下硬性约束。完整规范见上级 Skill 的 `references/`（若通过 git clone 获得）。

## 技术栈

Vue3 + Vant 4 + Vite，多语言中/英/越/泰，双端（访客端 + 安保端）。

## 硬性约束

| 约束 | 值 |
|---|---|
| 主色 | `#22BBB3`（primary-5），禁用主按钮 `#79DDD1`（primary-3） |
| 灰阶 | 海信 gray-1..10，弃 Vant 默认灰 |
| 字号 | 24/20/18/16/14/12，字距 0 |
| 圆角 | 12/16/20(Popup)/24 |
| 按钮 | 大 48 / 中 44 / 小 32 |
| 标签 | 24 / 28 / 32 |
| 间距 | 0 或 4 的倍数，Vant `4/8/12/16/24/32` |
| 输入框 | 311×76（Hug）· 搜索框 343×56（Hug） |
| 触摸目标 | ≥ 44px · 二维码 ≥ 200px |

## 状态标签色

已通过/入园 `#23C343` · 需审核/待确认 `#F9CC45` · 待登记 `#FF9A2E` · 未通过/退回 `#F76560` · 已取消/过期 `#C9CDD4` · 信息 `#E8F3FF`

## 目录约定

- 主题 token 集中在 `src/theme.css`（已覆盖 `--van-*`），**不要**在组件里硬编码颜色。
- Vant 组件在 `src/main.js` 统一注册。
- 新页面放到 `src/` 下，复用 Vant 组件，不重复造轮子。

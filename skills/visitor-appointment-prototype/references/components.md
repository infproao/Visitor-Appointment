# 标准组件（Components）

> 访客预约原型可用的标准组件、状态与用法。
> 组件分三层：通用组件（Vant 基础）→ 业务组件 → 组合规范（页面层拼装）。

## 一、通用组件（Vant 4 基础组件）

| 组件 | Vant 组件 | 用途 | 关键状态 |
|---|---|---|---|
| 文本输入 | `van-field` | 姓名/手机号/证件号/验证码 | 默认、聚焦、填充、错误、禁用 |
| 多行输入 | `van-field type=textarea` | 备注、说明 | 默认、填充 |
| 下拉选择 | `van-picker` / `van-field is-link` | 国籍、性别、证件类型、部门、园区 | 展开、选中 |
| 日期选择 | `van-calendar` / `van-date-picker` | 来访日期 | 选中、范围 |
| 时间选择 | `van-time-picker` | 时间段 | 选中 |
| 数字键盘 | `van-number-keyboard` | 人数、验证码 | 输入、确认 |
| 复选框 | `van-checkbox-group` | 协议勾选、核查项、入园人员 | 勾选、全选 |
| 单选 | `van-radio-group` | 入园人员角色 | 选中 |
| 搜索 | `van-search` | 人员/展厅/门禁搜索 | 默认、输入、清除 |
| 标签 | `van-tag` | 状态标签 | 见状态色映射 |
| 页签 | `van-tabs` | 审核/审批/出入记录 | 选中、未选中 |
| 弹窗 | `van-dialog` / `van-popup` | 入园操作、补授权、筛选 | 打开、关闭 |
| 按钮 | `van-button` | 主/次按钮 | 默认、禁用、按下 |
| 头像 | `van-image`（圆形） | 访客头像 | 有图、占位 |
| 上传 | `van-uploader` | 访客照片、车辆拍照 | 未上传、已上传 |
| 下拉菜单 | `van-dropdown-menu` | 展厅/园区筛选 | 展开、选中 |
| 空状态 | `van-empty` | 无预约记录 | 空态 |
| 通知条 | `van-notice-bar` | 授权提示、温馨提示 | 默认 |
| 步进器 | `van-stepper` | 人数选择 | 增减 |
| 步骤条 | `van-steps` | 基本信息/上传照片/确认 | 完成/当前/未完成 |
| 二维码展示 | 自定义 + 图片 | 通行证/提交成功 | 见 design-tokens 二维码规范 |

## 二、业务组件

| 组件 | 类型 | 结构 | 状态 |
|---|---|---|---|
| 工单信息卡片 | 卡片 | 顶部（日期 + 状态标签）+ 标题（人数/车辆）+ 字段行（来访公司/来访人）+ 底部预约编号 | 默认 |
| 场馆预约卡片 | 卡片（含二维码） | 标题 + 状态标签 + 字段 + 二维码图标 | 默认 |
| 审批记录卡片 | 时间线卡片 | 分组标题（直属领导/一级/二级）+ 节点（头像+姓名+状态标签+时间+意见） | 展开/折叠 |
| 动态/日志卡片 | 时间线卡片 | 时间 + 操作人 + 状态标签 + 正文 + 关键词行 + 图片缩略图 | 默认、展开更多 |
| 人员搜索行 | 列表行 | 头像 + 姓名 + 标签 + 操作图标（编辑/删除） | 默认、可编辑 |
| 车牌输入行 | 输入行 | 车牌号 + 编辑/删除图标 | 可编辑、只读禁用 |
| 语言切换按钮 | 普通按钮 | 文案（CN/EN/VN/TH） | 默认 |

## 三、状态标签（业务状态色映射）

| 状态 | 色值 | token |
|---|---|---|
| 已通过 / 入园 | `#23C343` | green-5 |
| 审核中 / 待确认（黄） | `#F9CC45` | gold-5 |
| 待登记 / 待入场（黄/橙） | `#F9CC45` / `#FF9A2E` | gold-5 / warning-5 |
| 未通过 / 已退回 / 已拒绝 | `#F76560` | red-5 |
| 已取消 / 已过期（灰） | `#C9CDD4` | gray-4 |
| 信息提示 | `#E8F3FF` | info-1 |

## 四、扫码取景组件（新增，自定义）

> 摄像头取景为原生能力，非 Vant 标准组件，需自定义实现。

```
扫码取景组件（ScanFrame）
├── 结构：原生摄像头流 + 半透明遮罩 + 取景框 + 底部相册入口 + 提示文案
├── 状态：
│   ├── 正常：取景框高亮，文案「将二维码放入框内」
│   ├── 相机权限拒绝：错误提示 + 引导去设置
│   ├── 不支持摄像头：错误提示「无法打开二维码，该浏览器暂不支持调用摄像头」
│   └── 相册导入：从相册选图识别
└── 触摸目标 ≥ 44px
```

## 五、组合规范（Composition）

> 弹窗、复合控件**不单独列为组件**，由基础组件拼装。以下为常见组合写法：

| 组合产物 | 组成（基础组件） |
|---|---|
| 添加同行人弹窗 | Popup + Field(姓名) + Field(证件) + 保存并继续/保存按钮 |
| 添加车辆弹窗 | Popup + Field(车牌) + 保存按钮 |
| 分享操作组 | 普通按钮组（保存二维码 / 复制链接 / 分享 Line） |
| 入境操作弹窗 | Popup + Search + 人员列表(Checkbox) + 取消/下一步 |
| 选择随入人员弹窗 | Popup + 人员列表(Checkbox) + 已选N人 + 确认按钮 |
| 筛选弹层 | Popup + Search + 单选/复选列表 |
| 补同意授权弹窗 | Popup + 二维码 + 文案「仅本次有效」 |
| 访客须知/隐私政策弹窗 | Popup + 文本 |

## 六、按钮规范

### 6.1 尺寸三档

| 尺寸 | 高度 | 状态 |
|---|---|---|
| 大 | 48px | ✅ |
| 中 | 44px | ✅ |
| 小 | 32px | ✅ |

### 6.2 类型 × 状态

| 按钮 | 样式 | 默认高度 |
|---|---|---|
| 主按钮 | 青绿实心（primary-5），圆角胶囊，白字 | 中 44px / 大 48px |
| 次按钮 | 白底描边（border），深字 | 中 44px / 大 48px |
| 禁用主按钮 | 浅青实心（primary-3），白字 | 中 44px / 大 48px |
| 禁用次按钮 | 浅底 + 浅字 + 浅边框 | 中 44px / 大 48px |
| 文字链接 | 青绿文字（color-link），如「更多 >」 | — |
| 小标签按钮 | 32px 高胶囊 | 小 32px |

> 主操作按钮（如「提交」「确认入园」）用大号 48px；常规表单「下一步」等用中号 44px；辅助/标签用 32px。

### 6.3 标签规范

| 类型 | 高度 | 状态 |
|---|---|---|
| 小标签 | 24px | ✅ |
| 中标签（胶囊） | 28px | ✅ |
| 大标签 | 32px | ✅ |

### 6.4 输入框与表单行

| 类型 | 尺寸 |
|---|---|
| 输入框宽度 | 311px（Fill） |
| 输入框高度 | 76px（Hug） |

> 依据：设计稿属性面板「311 Fill × 76 Hug」。其余待设计方确认。

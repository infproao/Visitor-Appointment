# 原型运行条件

## 技术

- Vue 3
- Vant 4
- Vite
- JavaScript
- Vue Router 4
- vue-i18n

## 数据和接口

- 本次范围只产出前端页面、路由、组件、样式、前端状态和 mock 数据。
- 不产出、不设计、不实现数据库、服务端 API、后端鉴权或服务端业务。
- Demo 默认使用内存数据、本地 fixtures 或假接口。
- 如果需求明确提供既有接口，可由前端调用；不实现接口本身。
- 不写入真实个人信息、API Key或生产数据。
- 页面字段和校验从 `requirements-input.md` 读取。

## 页面和设备

- 设计基准：375px移动端。
- 首版不实现浏览器状态栏、地址栏和底部浏览器工具栏。
- 桌面浏览器用于居中查看移动端原型，不改变页面设计宽度。

## 多语言

- 默认中文。
- 支持中文、英文、泰语、越南语。
- 点击语言按钮打开语言选择弹层并显示选中态。
- 具体翻译文案由需求输入或确认的语言资源提供。

## 资源

- Figma临时资源URL必须下载到项目资源目录后使用。
- 新建页使用 `bg-image-2` 资源，保持375×486比例。
- 所有二维码页面使用 `assets/images/qr-placeholder.png`。
- 首版不生成真实二维码。

## 摄像头与扫码

- 首版扫一扫只展示模拟取景和结果状态。
- 不调用真实摄像头。
- 相机权限、识别失败和相册识别状态保留为可扩展交互状态。

## 验收

- 必须执行生产构建。
- 必须执行 `git diff --check`。
- 必须按 Figma截图检查页面尺寸、颜色、字段、按钮、弹层和状态。
- 必须记录未验证的Figma节点或资源。

# Skill 质量门禁

## 需求门禁

- [ ] 目标端和页面范围已确认。
- [ ] 每个页面已确定 page type。
- [ ] 字段、必填状态和选项来自需求输入。
- [ ] 资源来源和确认状态已记录。
- [ ] 待确认项没有被写成固定事实。

## 模板门禁

- [ ] 已按 `page-generation-decision-tree.md` 判断模板匹配度。
- [ ] 能套用模板的页面没有重新设计。
- [ ] 无模板页面只使用已注册组件和 Token。

## 组件门禁

- [ ] 所有依赖组件来自 `component-registry.md`。
- [ ] `pending` 组件没有被临时 HTML 替代。
- [ ] 没有页面内重复实现已注册组件。
- [ ] Vant 默认视觉已被 Figma样式覆盖。

## 视觉门禁

- [ ] 375px基准布局符合 Figma。
- [ ] 颜色使用海信 Token。
- [ ] Field、Button、Steps、Checkbox、Popup 和 Picker 状态符合组件规格。
- [ ] 错误提示位置和边框状态符合需求。
- [ ] 二维码、空状态和背景资源使用已确认资源。

## 运行门禁

- [ ] 原型使用模拟数据。
- [ ] 不依赖个人绝对路径或临时 Figma URL。
- [ ] 生产构建通过。
- [ ] `git diff --check` 通过。
- [ ] 页面实际渲染截图已与 Figma 对照。

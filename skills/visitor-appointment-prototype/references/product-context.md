# 产品上下文（Product Context）

> 访客预约产品的定位、用户与业务知识。

## 一、产品定位

海信访客预约 H5，用于访客预约、审批、到场核验、出入记录的全流程管理。移动端（浏览器内运行），支持多语言与多地区。

| 项 | 内容 |
|---|---|
| 产品名 | 访客预约（Visitor Appointment） |
| 形态 | 移动端 H5（浏览器内运行） |
| 技术栈 | Vue3 + Vant 4 |
| 多语言 | 中文 / 英文 / 越南语 / 泰语 |
| 地区版本 | 越南版、泰国版、中国版 |
| 设计基准 | 375pt 宽画板 |

## 二、双端角色

| 端 | 角色 | 核心场景 |
|---|---|---|
| 访客端（用户端） | 访客 / 被访人 | 预约填报、查记录、通行码、审批 |
| 安保端（管理员端） | 安保 / 门禁 | 出入登记、核验、入园/离园、门禁控制 |

## 三、用户与业务知识

### 3.1 核心业务对象

| 对象 | 说明 |
|---|---|
| 预约人（访客） | 发起预约的人，填写本人信息 |
| 被访人 | 园区内接待方，负责审批 |
| 同行人 | 随预约人一起入园的人，需「同意授权」 |
| 车辆 | 随行的车辆，需登记车牌 |
| 预约单 | 一次预约的载体，含唯一预约编号 |

### 3.2 核心流程

```
预约填报 → 被访人审批 → 到场安保核验 → 入园 → 离园
```

### 3.3 审批流

- 层级：直属领导审批 → 一级审批人 → 二级审批人（三级审批）
- 审批状态：审核中 / 已通过 / 已退回 / 已过期 / 待确认

### 3.4 关键业务规则

| # | 规则 |
|---|---|
| R1 | 通行证「仅当日有效」，过期需重新预约 |
| R2 | 同行人需「同意授权」后方可入园 |
| R3 | 入园需完成证件核验 / 随身物品确认 / 禁带物品自查三项核查 |
| R4 | 必填项用 `*` 标记 |
| R5 | 审批流含驳回/入园，状态含审核中/已通过/已退回/已过期 |

### 3.5 业务边界（不在 Skill 约束范围）

- 车牌、证件号、手机号的国际化格式校验（业务侧负责）
- 具体审批流转规则、审批人配置（业务侧负责）

## 四、地区差异（部分，待业务补全）

| 差异点 | 越南版 | 泰国版 | 中国版 |
|---|---|---|---|
| 证件类型 | 越南公民身份证 | 泰国外国人身份证 | 居民身份证 |

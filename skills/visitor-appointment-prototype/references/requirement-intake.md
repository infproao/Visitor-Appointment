# 需求接收流程

本文件定义需求进入 Skill 后的确认流程；字段、资源和校验的具体结构见 `requirements-input.md`。

## 流程

1. 确认目标端、页面范围和页型。
2. 确认页面字段、必填状态、选项和业务文案。
3. 确认国家/地区、语言和资源来源。
4. 确认模拟数据、校验配置和页面状态。
5. 逐页执行 `page-generation-decision-tree.md`。
6. 需求确认前不生成页面代码。

## 输出

需求确认结果必须包含：

- 页面清单；
- 页面类型；
- 模板匹配结果；
- 组件依赖；
- 资源来源和确认状态；
- 待确认问题；
- 本次不处理的范围。

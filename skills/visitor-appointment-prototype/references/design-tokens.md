# 设计变量（Design Tokens）

> 访客预约原型 Skill 的设计变量规范。
> 适用技术栈：Vue3 + Vant 4。

> **状态标记约定**：
> - ✅ 已确认 = 来自设计方口述、设计稿属性面板标注、或海信 token 文件原文
> - ⚠️ 待确认 = 从 SVG 几何量测出，尚未经设计方背书
> - 📋 方案建议 = 本 Skill 拟定的映射/规范，非资料既有事实

## 三、字号（✅ 设计方确认）

| 字号 | 字重 | 用途 |
|---|---|---|
| 24px | Bold | 页面大标题 |
| 20px | Bold/Medium | Dialog 标题（大档） |
| 18px | Medium | Dialog 标题（小档） |
| 16px | Regular | 正文、输入内容、占位「请输入」、卡片主标题 |
| 14px | Regular | 辅助信息、次要文字 |
| 12px | Regular | 输入框错误提示、时间戳等小字 |

> 字距（letter-spacing）统一 0。

---

## 四、圆角（✅ 设计方确认：12/16/20/24）

| 值 | 用途 |
|---|---|
| 12px | 卡片、输入框、普通容器 |
| 16px | 中等卡片/面板 |
| 20px | Popup 弹窗 |
| 24px | 大卡片/全屏面板 |

> ⚠️ 「按钮胶囊圆角」的具体数值（如 rx=22 / rx=23 等）从 SVG 测得，待设计方确认统一值。

---

## 五、间距（✅ 设计方确认：0 或 4 的倍数，直接跟 Vant 默认梯度）

| Vant 变量 | 值 | 用途 |
|---|---|---|
| `--van-padding-base` | 4px | 最小内边距基准 |
| `--van-padding-xs` | 8px | 小间距 |
| `--van-padding-sm` | 12px | 常规小间距 |
| `--van-padding-md` | 16px | 常规内边距（页面/卡片 insets） |
| `--van-padding-lg` | 24px | 区块间距 |
| `--van-padding-xl` | 32px | 大间距 |

> 规则：间距为 0 或 4 的倍数，梯度直接沿用 Vant 默认 `4/8/12/16/24/32`，不另立一套。

## 八、二维码规范（📋 方案建议）

| 参数 | 值 |
|---|---|
| 最小展示尺寸 | ≥ 200×200px |
| 弹窗/卡片内 | ≥ 160×160px |
| 静区 | 四周 ≥ 16px |
| 对比度 | 深码浅底，禁反白 |
| 缩放 | 等比，禁拉伸 |

> 📋 以上为通用扫码可用性建议，非设计稿标注；若为闸机/枪机固定距离扫码，需按设备规格实测。

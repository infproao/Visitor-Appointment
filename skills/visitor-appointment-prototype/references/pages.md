# 典型页面与业务场景（Pages）

> 访客预约原型的典型页面 + 特殊处理页面。
> 每个页面标注：端、关键元素、用到的组件（通用 + 业务）。

## 一、访客端（用户端）页面

### 1. 访客预约首页（特殊处理页）
- **端**：访客端
- **关键元素**：欢迎横幅、今日日期 + 通行凭证二维码、主按钮「立即预约」、次按钮「查看预约记录」、访客须知卡片、语言切换按钮
- **组件**：主/次按钮、横幅卡片、二维码、访客须知卡片、语言切换（普通按钮）

### 2. 新建预约表单（典型页）
- **端**：访客端
- **结构**：步骤条（基本信息→上传照片→确认）+ 分段（预约信息/访客信息/证件照片）
- **关键元素**：访客信息（照片上传、姓名、手机号、证件）、同行人列表 + 添加、车辆列表 + 添加、隐私协议复选、主按钮「下一步」
- **组件**：步骤条、Field、上传、人员标签组、添加同行人弹窗、添加车辆弹窗、Checkbox、主按钮

### 3. 预约记录列表（典型页）
- **端**：访客端
- **关键元素**：待确认提示条、记录卡片（日期/状态/访问人/时间/通行证二维码）
- **组件**：NoticeBar、工单信息卡片、状态标签

### 4. 预约记录空状态（典型页）
- **端**：访客端
- **关键元素**：空状态插画 + 文案
- **组件**：Empty

### 5. 通行证二维码页（特殊处理页）
- **端**：访客端
- **关键元素**：状态标签「待入区」、当日有效提示、园区名称、大二维码、预约编号、查看更多
- **组件**：状态标签、二维码、预约编号行

### 6. 失效通行证页（典型页）
- **端**：访客端
- **关键元素**：插画 + 失效文案 + 「重新预约」
- **组件**：Empty、次按钮

### 7. 提交成功页（典型页）
- **端**：访客端
- **关键元素**：成功对勾、标题「提交成功」、二维码、分享按钮组（保存二维码/复制链接/分享Line）、预约单号、查看详情
- **组件**：二维码、普通按钮组、预约编号行

### 8. 预约详情页（典型页）
- **端**：访客端
- **关键元素**：标题 + 状态标签、Tab（审批记录/操作记录）、目的地、预约信息、访客信息、同行人、车辆、审批记录
- **组件**：Tabs、信息卡片、审批记录卡片、状态标签

### 9. 补同意授权弹窗（典型页）
- **端**：访客端
- **关键元素**：二维码 + 「仅本次有效」
- **组件**：Popup + 二维码 + 文本（组合规范）

## 二、安保端页面

### 10. 访客出入登记列表（特殊处理页）
- **端**：安保端
- **关键元素**：筛选（园区/部门/搜索）、记录卡片（头像/日期/状态标签/访客信息/车辆/拜访部门/预约编号）、悬浮扫一扫
- **组件**：DropdownMenu、Search、工单信息卡片、状态标签、扫码入口

### 11. 扫一扫页（特殊处理页）
- **端**：安保端
- **关键元素**：摄像头取景框、提示「将二维码放入框内」、相册入口
- **组件**：扫码取景组件（自定义，见 components.md）

### 12. 安保详情页（典型页）
- **端**：安保端
- **关键元素**：标题 + 状态标签、Tab（审核信息/审批记录/出入记录）、访客信息、同行人、车辆、驳回/入园按钮
- **组件**：Tabs、信息卡片、审批记录/动态卡片、主/次按钮

### 13. 入境操作弹窗（典型页，两步）
- **端**：安保端
- **关键元素**：搜索 + 人员复选列表、取消/下一步；第二步：选入园人员、照片上传、核查项、备注、上一步/提交
- **组件**：Popup + Search + Checkbox 列表 + 按钮（组合规范）

### 14. 选择随入人员弹窗（典型页）
- **端**：安保端
- **关键元素**：人员列表（复选）、已选N人、确认并入场
- **组件**：Popup + Checkbox 列表 + 按钮（组合规范）

### 15. 门禁控制页（典型页）
- **端**：安保端
- **关键元素**：搜索门 + 门禁单选（东/南/西门）
- **组件**：Search、Radio

### 16. 筛选弹层（典型页）
- **端**：安保端
- **关键元素**：人员/展厅/时间筛选，单选/复选/搜索
- **组件**：Popup + Search + 单选/复选列表（组合规范）

## 三、通用弹窗（多端复用）

### 17. 访客须知弹窗
- **组件**：Popup + 文本

### 18. 隐私政策弹窗
- **组件**：Popup + 文本

### 19. 选择弹窗（国籍/性别/证件类型/部门）
- **组件**：Picker / Popup + 列表 + 选中态

## 四、页面覆盖度小结

- 共 19 个页面/弹窗场景。
- 通用组件 + 业务组件可拼出 18 个，仅「扫一扫」需新增「扫码取景」自定义组件。
- 大二维码、成功对勾归为 `assets/images/` 图标/图片资源，不作为组件。

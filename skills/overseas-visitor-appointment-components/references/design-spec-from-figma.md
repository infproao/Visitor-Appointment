## 零、用户裁决（2026-11-05）：以设计稿中的为准

用户对本文件第八节的冲突作出裁决：**「以设计稿中的为准」**。

本文件据此把「设计稿」定义为 **Figma 节点的实际渲染属性**——`fills` / `style` / `cornerRadius` / `effects` / auto-layout 的 `itemSpacing` 与 `padding*`——而不是画板上作为说明的文字标注，也不是外部海信 token 文件或 Vant 默认值。**色卡的名称与分组标题**（Primary、Gray-1…8、Elevation 0…4 等）仍沿用画板文字，只作命名用途；规范**数值**一律取节点属性。

裁决依据（【事实】，模板页 5316 节点 SOLID fill 全量统计）：

| 文字标注色值 | 实测出现次数 | 文字标注色值 | 实测出现次数 |
|---|---|---|---|
| `#00AAA6` | 31 | `#323233` | 0 |
| `#36CFC9` / `#07C160` / `#EE0A24` | 0 / 0 / 0 | `#646566` / `#969799` / `#C8C9CC` | 0 / 0 / 0 |
| `#FFFBE8` / `#FAAB0C` / `#FF976A` / `#ED6A0C` | 0 / 0 / 0 / 0 | `#DCDEE0` / `#EBEDF0` | 0 / 0 |
| `#1989FA` | 0 | `#576B95` | 0 |

即：上表 16 个 Vant 系标注色值中，**15 个在整份设计稿 2499 个 SOLID fill 里出现 0 次**；唯一例外 `#00AAA6`（同时是 token `primary-6`）出现 31 次。需补充说明：另有 4 个「标注与色块一致」的值未列进本表 —— `#FFFFFF`(488) / `#000000`(120) / `#F2F3F5`(41) / `#F7F8FA`(21) —— 它们确实被节点使用。结论只针对上表这些**标注与色块不一致**的色值：色块 fill 才是真正画出来的颜色。

因此：

- 颜色一律取**色块 fill / 节点实际 fill**；灰阶编号采用设计稿的 `Gray-1..8`。
- 字号、行高、间距、圆角、阴影一律取**节点实测值集合**，不再限定为早期的「12/16/20/24 圆角」「12/14/16/18/20/24 字号」「仅 4 的倍数间距」。
- 文字标注列降级为「设计稿内的历史说明文本」，不作为规范值；但其中 `#00AAA6` 作为独立色值仍保留在实测用色表里。
- `design-tokens.md` 的早期确认值**不删除、不覆盖**，只在文件头加注指向本裁决；后续是否回写由前端另行确认。

【仍待确认】若「以设计稿中的为准」实际指的是画板上的**文字标注列**而非色块实际渲染值，本裁决需整体反转——请明确告知。

原始参数【事实】：

- Elevation 0：`rgba(0,0,0,.10)` offset(0,0) blur 4

- Elevation 2：三层 —— `.10` (0,5) blur5 spread-3；`.06` (0,8) blur10 spread1；`.05` (0,3) blur14 spread2

## 七、变量系统读取限制【事实 / 待确认】

- 模板页有 **1965 个节点**带 `boundVariables`，覆盖 `fills`(1854)、`strokes`(140)、`padding*`、`itemSpacing`、`fontSize`、`fontFamily`、`fontWeight`、`lineHeight`、`opacity` 等 —— 说明设计稿确实用了 Figma 变量驱动。
- 共出现 **115 个不同 VariableID**，但当前 Figma 令牌调用 `/v1/files/{key}/variables/local`、`/variables/published`、`/styles`、`/components` 均返回 **403 Forbidden**。
- 因此**变量/样式的正式名称（token 名）无法从 Figma 侧读取**，本文件中的命名（Gray-1、Primary、Elevation 0…）均取自色卡与画板上的 TEXT 标注，不是变量系统里的名字。
- 【待确认】如需完整 token 名与多模式值，需为 Figma 令牌补 `file_variables:read` scope（或换有权限的账号）后重读；届时才能把「Figma 变量名」与 `design-tokens.md` 的 token 名做严格一一对应。

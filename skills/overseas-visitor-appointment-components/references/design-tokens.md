# 设计变量（Design Tokens）

> **本文件是颜色 / 字号 / 间距 / 圆角的权威入口**（2026-11-13 按原始结构回归后重写）。
> 权威依据：`design-spec-from-figma.md` **第九节**（可落地最终规范值）、**9.7**（2026-11-06 用户 7 项数值裁决）、**11.6**（渲染口径重算）。
> 2026-11-05 用户裁决「以设计稿中的为准」：数值一律取 Figma 节点实际渲染属性，不取画板说明文字标注、外部海信 token 文件或 Vant 默认值。
> 统计口径为**渲染口径**：只采集可见节点，隐藏节点与隐藏状态变体不进入规范值。
> 早期基于海信 `Mode-1.tokens.json` 的版本已归档到 `history/design-tokens-legacy.md`，**不再作为取值依据**。
> ⚠️ 代码侧 `src/theme.css` 的 `--van-*` 变量与组件样式**尚未按 9.7 全量同步**；改代码前需确认。

## 二、字体、字号、行高

- 字体族 `PingFang SC`；字重 `400 / 500 / 600`；组件内字距 0。
- **组件字号集合（7 档）**：`12 / 13 / 14 / 16 / 18 / 20 / 24 px`。用户裁决删除 `10 / 17 / 72`；`22 / 30 / 36` 为画板标题与标注，不计入。
- **行高 = 字号 × 1.5**：

| 字号 px | 12 | 13 | 14 | 16 | 18 | 20 | 24 |
|---|---|---|---|---|---|---|---|
| 行高 px | 18 | 19.5 | 21 | 24 | 27 | 30 | 36 |

> 【差异留档】实测最高频配对 `14/22`(164) 不是 1.5 倍；落地时 14px 行高按 **21px**，与 Figma 当前 22px 不同，需在组件层同步。`13 × 1.5 = 19.5px` 半像素取整问题见 11.4，待确认。

## 三、间距

- **主梯度**（itemSpacing，渲染口径频次）：`8`(612) / `12`(328) / `4`(298) / `16`(145)。
- **itemSpacing 允许值（16 个，全为整数）**：`2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 / 32 / 36 / 40 / 46 / 60 / 70 / 80`。已按裁决删除小数 `3.14` 与 `5 / 11`。
- **padding 允许值**：`2 / 4 / 5 / 6 / 7 / 8 / 9 / 10 / 12 / 14 / 16 / 18 / 20 / 24 / 26 / 40 / 50 / 52 / 60 / 62 / 70 / 79 / 80 / 100`。已按裁决删除 `13 / 23`；小数 `86.8` 一并移出（推断，待确认）。主值 `16`(521) / `12`(520) / `10`(238) / `8`(230) / `4`(108) / `6`(69)。
- 不再附加「仅 4 的倍数」限制；padding 里 `1 / 3 / 5 / 7 / 9 / 79` 奇数实测值暂留（用户只点名 `13 / 23`）。

## 四、圆角

| 类别 | 值 | 典型节点 |
|---|---|---|
| 小圆角 | `2 / 3 / 4 / 8 / 10` | `tag` 2、`uploader` 4、`dropdown-menu` 8、`alert` 10 |
| 卡片 / 容器 | `12 / 16 / 20 / 24` | `Select List` 12、`dialog` 16、`button` 20、`card` 24 |
| **全圆角** | **`999`** | 统一替代 `40 / 50 / 99 / 100 / 999 / 9999` 六种写法 |

> 两页渲染口径下 `≥40` 的 6 个圆角值共 216 处，按 `radius ≥ min(宽,高)/2` 判定 100% 为全圆角。`17px` / `20px` 落在小控件上的接近半高值未归一。

## 八、使用约束

- 页面与组件取色 / 取字号 / 取间距一律以本文件为准；与 `history/design-tokens-legacy.md` 冲突时**以本文件为准**；
- 本文件是「规范值」，`src/theme.css` 与组件样式是「实现值」。二者不一致时**如实登记差异**，不要为了对齐文档而顺手批量改组件视觉（见 `design-principles.md` 第一、二节）；
- `npm run gate` 的 token 检查只拦「新增明显越界值」（如 `10px` 字号、`13px` padding），不强制存量代码改造。
